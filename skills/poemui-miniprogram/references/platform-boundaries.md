# 平台边界

- H5 预览是 PoemUI 能力镜像，不是微信 API 成功证明。
- 微信 `open-type`、授权、手机号、头像、订阅消息、支付、剪贴板等能力必须在真实小程序环境调用，并处理平台返回。
- 开发者工具通过不等于 iOS/Android 真机通过；字体、触摸、键盘、安全区、授权、网络和读屏需要单独记录。
- `build-npm` 只证明构建阶段完成，不证明组件路径、运行态或真机可用。
- 浏览器 `navigator.clipboard` 与微信 `wx.setClipboardData` 是不同实现；不要用一端结果替代另一端。
- 动效默认 500ms、最长 1000ms；低动效为 1ms。避免 `height:auto` transition 和 `display:none` 瞬移。
- 平台能力缺失或权限被拒时，给用户明确下一步；不要显示成功占位。

报告至少分开列出：源码合同、静态测试、npm 构建、微信模拟器、H5、真机。未执行的项写“未验证”或 `pending-device`。
