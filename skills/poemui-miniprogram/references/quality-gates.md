# 质量准入门禁

组件级新增、修改、迁移和删除在实施前逐项通过以下门禁。门禁不是评审建议；不满足时必须缩小 API、调整职责或补齐实现链路。

## 1. API 准入

只有同时满足以下条件才新增 Prop、Event、Slot、Method 或全局配置：

- 解决可复用的组件职责，不承载单页文案、业务状态、路由、订单、支付或演示专用逻辑。
- 现有 API、Slot 或 PUI 组合无法清晰表达；不得为一次页面补丁制造永久公共接口。
- 名称、类型、默认值、受控/非受控关系、事件时机和失败语义明确；保留 `0`、`false`、空字符串和空数组。
- 默认值向后兼容且无需调用者补 CSS 才可使用；局部 API 与 `visualConfig` 的优先级和并集/覆盖关系明确。
- 小程序源码、组件合同、API 文档、示例、H5 镜像、专项测试、导出和分发产物能够同步闭环。

不能证明公共复用价值时，优先使用现有 Slot、组合能力或页面状态；不能以“以后可能用到”准入 API。

## 2. 默认态质量

组件在最少必需参数下就是可交付状态：

- 有完整可见结构、合理尺寸、排版、留白、点击区和无障碍名称，不依赖演示页补 margin、宽高、背景或定位。
- 默认文案与装饰保持克制；可选描述、图标、阴影、毛玻璃和强调色不应成为修复默认态的前提。
- light/dark、390px、长文本、空内容和低动效下不溢出、不坍塌、不产生双层 Surface。
- 默认交互可完成：输入能持续聚焦，按钮可点击，浮层可关闭，受控值可回写，失败和取消有恢复路径。
- 默认样式表达组件本身的语义，不展示业务成功、虚假数据或只为 Showcase 成立的状态。

“传一组特殊 Props 后很好看”不能证明默认态合格。

## 3. 组件职责与状态资格

- 组件只拥有自身结构、交互原语和公开状态；页面拥有业务数据、路由、网络编排和结果决定，父级拥有受控值真相。
- 组件可以发出意图事件，但不能把点击、复制、上传、支付或数据库请求直接宣告为成功。
- 只有天然拥有数据呈现生命周期的组件才准入 loading/error/empty/retry。纯布局、展示叶子、操作按钮和 Slot 容器不得复制一套伪状态系统。
- 阴影、毛玻璃、边框、等距和滚动资格按组件结构判断，不因全局开关存在就让所有节点消费效果。
- 复合组件已组合 Input、Cell、Button、Loading、Empty 等 PUI 子组件时，复用子组件合同；父级不得穿透重造其尺寸、Surface 和反馈语义。

状态没有明确所有者时先确定所有权，不同时在页面、父组件和子组件各存一份。

## 4. 单一 Surface、滚动与焦点所有权

同一用户任务在同一层级遵守三个“一”：

1. **一个可见 Surface**：同一组件外壳不再嵌套第二个无职责背景、边框、圆角、阴影或毛玻璃面板。
2. **同轴一个滚动所有者**：Popup、Sheet、Dialog 等由 Content 持有垂直滚动；Header/Footer 固定可见。内层只有确有独立浏览语义时才建立自己的滚动区，并禁止与父级争抢同一手势。
3. **一条焦点所有权链**：触发者负责打开，浮层/输入组件负责活动焦点，关闭后恢复到原触发者。受控更新不得重建输入节点导致失焦；H5 焦点陷阱不能反向改变小程序结构。

出现双层底色、两根滚动条、滚动像被卡住、输入一聚焦就失焦或关闭后焦点丢失时，先查所有权，不用 z-index、额外高度或延迟定时器掩盖。

## 5. 删除闭环

用户明确删除组件、API、路由或能力时，以“后续 Agent 无法再把它识别为当前能力”为完成标准：

- 删除真实源码、公开导出、`usingComponents`/注册、路由、目录和搜索索引。
- 删除 H5 镜像、兼容别名、演示、API/WXML 说明、组件合同、测试 fixture 和发布清单中的当前能力描述。
- 更新生成器真相源并重新生成 `miniprogram_dist`、目录、Ledger 摘要和安装产物；不得手工只删生成结果。
- 更新或关闭 Feedback Ledger 原始记录，保留必要的历史证据但不得让历史文本继续表现为有效 API。
- 只有用户明确要求时，才在外部发布说明保留最小迁移说明。

目录消失但仍可从导出、文档、搜索、H5、测试或 npm 产物访问，均不算删除完成。

## 6. 证据必须与结论匹配

| 证据 | 可以证明 | 不能证明 |
| --- | --- | --- |
| 源码与合同审计 | 实现意图、API 和结构存在 | 编译、交互或真机正确 |
| 静态扫描与专项测试 | 指定合同和回归样例通过 | H5 几何、小程序运行或真实平台能力 |
| 构建、打包、build-npm | 语法、依赖和产物链可生成 | 页面可用、交互正确或真机通过 |
| H5 真实浏览器交互与计算样式 | H5 镜像行为、几何和样式 | 小程序端或真机一致 |
| 微信开发者工具实际交互 | 当前工具版本和模拟环境可运行 | iOS/Android 真机、网络、权限和性能 |
| iOS/Android 真机操作 | 对应设备、系统和版本下的真实结果 | 未覆盖设备或未来版本 |
| 云数据库/外部服务写入并回读 | 指定环境中的真实数据闭环 | 其他环境、权限角色或发布态均正常 |

最终报告把每条“已验证”结论绑定到命令、文件、截图、计算样式、回读或真机观察。证据等级不足时写“未验证”，不得用构建成功、Token 已声明、根节点 class 已切换或静态页面存在替代运行结论。
