# Tour 组件语义合同

本文是 PoemUI Tour 的长期合同。修改前必须查询：

`npm run feedback:list -- --component tour`

Props、事件、Slot 与方法完整表以 `docs/COMPONENT_API.md` 为准。

## 1. 组件定位

Tour 围绕页面中真实存在的目标逐步说明关键操作。它拥有唯一遮罩、当前步骤、目标测量、面板定位与操作链；不负责决定用户是否永久完成引导，也不写本地存储。目标只接受单一 `#id` 或 `.class`，避免复杂选择器跨组件误命中。

## 2. 结构、Surface 与滚动

结构固定为四块遮罩、一个非交互高亮框和一个独立面板。高亮孔允许目标保持可见；遮罩阻止外围触摸穿透，面板是唯一可交互 Surface。面板按 Header/Content/Footer 组织，内部使用 PUI Button；正文过长时只允许面板内容在视口上限内滚动。

Tour 属于 `edge-to-edge` 预览。面板具备独立 Surface 资格，可跟随阴影、毛玻璃、大圆角、边框与等距模式；遮罩默认半透明，仅 `overlayBlur=true` 或全局毛玻璃开启时模糊。高亮框与状态边界不受全局边框关闭影响。

## 3. 受控、失败与事件

`visible/defaultVisible` 与 `current/defaultCurrent` 分别独立判定受控。下一步按 `current-change → change` 请求回写；最后一步发布 `finish` 后请求关闭。跳过先发布 `skip`，关闭统一发布 `close → visible-change(false)`。

步骤为空、选择器非法、目标不存在或平台不能测量时必须发布 `error` 并 fail-closed 请求关闭，禁止在错误坐标显示面板。关闭遮罩由 `closeOnOverlay` 决定；目标孔不应成为隐式关闭区。

## 4. 定位、可访问性与 H5

定位优先尊重 top/right/bottom/left；空间不足时按可用空间回退，面板始终保留 16px/32rpx 视口安全边界。H5 使用真实 DOM `querySelector` 与同一回退规则，不得将面板固定在演示假目标旁。

根为 dialog，提供步骤总数与当前序号；打开后 H5 焦点进入第一个操作，Tab 留在面板，Esc 请求关闭，关闭后恢复触发入口。小程序端保持按钮可访问名称与低动效，平台焦点差异必须如实记录。

## 5. 明确禁止与修改闭环

- 禁止使用一整块不透明面板遮住目标，或用截图模拟目标。
- 禁止目标缺失时继续显示、越界或宣称完成。
- 禁止让页面侧重复实现遮罩、面板定位或步骤按钮。
- 禁止 H5 反向决定小程序选择器与测量实现。

修改需同步小程序、H5、API、独立页、元数据、外观矩阵、Ledger、专项测试、产物与本地安装，并验证 390px、深浅色、阴影/毛玻璃/边框/大圆角/等距、目标缺失和受控回写。
